Use the exact category label `CONSUMO MASIVO` for new mass-consumption brand cards on the Distribution page. Do not substitute a generic label such as “Marca representada.”

**Why:** The user corrected the generic category and asked for the same “CONSUMO MASIVO” label used by the other consumer brands.

**How to apply:** When adding a brand to the Distribution portfolio, use `CONSUMO MASIVO` unless the user explicitly gives a different category.
